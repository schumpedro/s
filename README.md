# 🐉 Arena Pokémon

Projeto de cadastro de Pokémons usando a PokeAPI. Busque um Pokémon pelo nome, cadastre com o nome do treinador e coloque ele na arena para batalhar.

🔗Site: https://schumpedro.github.io/s/

![Print do projeto](print.png)

<!--  Funcionalidades -->

- Busca automática de tipo e CP pela PokeAPI enquanto você digita
- Cards coloridos de acordo com o tipo do Pokémon
- Batalha: o Pokémon com maior CP ganha destaque dourado
- Bloqueia Pokémon repetido na arena
- Arena salva no navegador (não some ao recarregar)
- Sugestões dos Pokémons e treinadores digitados recentemente
- Botões para remover um card ou limpar a arena toda

<!--  Tecnologias -->

- HTML
- CSS
- JavaScript
- PokeAPI (https://pokeapi.co)

<!-- Como rodar -->

Baixe os arquivos e abra o `index.html` no navegador. Não precisa instalar nada.
